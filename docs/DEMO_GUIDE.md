## 演示动线（约 15 分钟）

### 1. 工作台（1 分钟）
登录 admin → 首页即合同工作台：问候语、任务计数桶（待办审批/草稿/审批中/已驳回/待归档/已签订）、我的待办、我负责的合同、最近审批记录。点任一计数桶直达对应清单。

### 2. 起草中心：四种建合同方式（3 分钟）
合同管理 → 起草中心：
- **选择标准模板起草**：选「采购合同」→ 范本 DOCX 自动生成正文 v1，填核心字段+该类型扩展字段（交付日期/验收标准/质保期）→ 保存草稿；
- **已有文件上传起草**：新建后在详情上传本地 DOCX；
- **复制已有合同**：从台账挑一份复刻（字段+签约方+正文全带走）；
- **合同续签**：对已签订合同一键生成续签草稿（详情页可见"续签自 HTxxxx"关联）。

### 3. 合同台账（1 分钟）
状态页签（全部/草稿/审批中/审批通过/已签订/已驳回）、筛选、金额与状态标签；标题下的"复制/续签自"关联小字。

### 4. 详情页：文档为中心（3 分钟）
打开任一合同：左侧**正文 DOCX 直接渲染预览**（可切版本、下载），右侧信息面板（基础信息/文档版本/参与人/审批记录/审计轨迹），顶部阶段条 草稿→审批中→审批通过→已签订。

### 5. 审批闭环（4 分钟）
1. 挑一份草稿 → 【提交审批】（弹窗显示绑定版本+SHA-256+审批人预览）；
2. 切账号 yudao（法务）→ 审批中心 → 待办任务 → 打开（内嵌合同快照、可下载绑定正文）→ 通过；
3. 切回 admin → 待办 → 通过 → 合同变为「审批通过」；
4. 演示驳回路径：台账「已驳回」页签里有现成例子（驳回意见可在审批记录看到；重新上传新版本可再提交，旧审批记录保留）。

### 6. 归档定稿 → 已签订（2 分钟）
在「审批通过」的合同详情 → 【上传盖章件归档】：传盖章扫描件+登记签订/生效/到期日期 → 生命周期变「已签订」，正文出现 MANUAL_FINAL 定稿版本（冻结），阶段条走满。

### 7. 权限与审计（1 分钟）
- 切 test 账号：台账看不到未授权合同，硬拼 URL 也被服务端拒绝；
- 切回 admin，在详情「参与人」给 test 授权查看/下载 → test 立即可见；撤销后立即不可见；
- 「审计轨迹」完整记录创建/上传/提审/审批/下载/授权/归档全过程。
