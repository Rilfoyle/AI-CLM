## 一、新建相对方（签约方）

我方主体和相对方在同一处维护，用「主体归属」区分。

1. 左侧菜单：**合同管理 → 签约方** → 点【新增】。
2. 填写：
   - **主体归属**：选「我方主体」或「相对方」（新建合同时，我方主体/相对方两个下拉分别只列各自归属的记录）；
   - **主体类型**：企业 / 个人；
   - **名称**、**统一社会信用代码**（个人填证件号）、联系人、电话、地址、状态。
3. 保存后即可在新建合同时选择。

> 建议先把公司自己的签约主体录成「我方主体」，再录常用客户/供应商。

## 二、新建合同类型 + 设计合同表单（扩展字段）

合同的表单 = 核心固定字段（标题/金额/日期/签约方等，所有类型共有）+ 该「合同类型」定义的**扩展字段**。扩展字段按版本管理：**草稿可改，发布后不可变**，历史合同永远按它创建时引用的版本展示。

1. **合同管理 → 合同类型** → 【新增】：填**类型编码**（英文，如 `sales`）、**类型名称**（如「销售合同」）、默认**审批流程标识**（不改就用 `clm_contract_approval_v1`）→ 保存。系统自动生成「版本 1（草稿）」。
2. 该行点【版本/设计】打开版本抽屉 → 草稿行点【设计表单】进入设计器：
   - 左侧组件面板**拖拽**输入框/数字/日期/下拉/上传/用户选择器等到画布，右侧配置字段名、标题、**是否必填**等（和飞书审批的表单搭建方式一致）；
   - 顶部可改**审批流程**下拉（该类型合同提审时走哪条流程，可下拉选择已发布流程，也可手输标识）；
   - 点【保存】存草稿，点【保存并发布】直接发布。
3. **发布后**：类型才能用于新建合同。要改表单 → 回到版本抽屉点【新建草稿版本】（自动复制当前发布版），改完再发布；已有合同不受影响。

> 必填校验是服务端强制的：合同创建/提审时，扩展字段缺必填项或出现表单外字段都会被拒绝。

## 三、新建审批流（流程编排）

1. **流程配置 → 审批流程设计** → 点分类下的【新建模型】，进入 4 步向导：
   > 流程配置下只有前三项是"配置"（审批流程设计 / 流程分类 / 审批人分组）；「运行监控」里的流程实例、流程任务是运行后的排障视图，配流程不需要碰。
2. **① 基本信息**：
   - **流程标识**：英文唯一 key（字母开头，如 `clm_contract_approval_v2`）——之后合同类型就是靠这个 key 关联流程的；
   - **流程名称**（如「大额合同审批」）、**流程分类**（选「合同管理」）；
   - **流程类型**：选 **SIMPLE 设计器**（仿钉钉/飞书画布；懂 BPMN 也可选 BPMN 设计器）；
   - 流程管理员：选自己。
3. **② 表单设计**（合同审批的关键配置）：
   - **表单类型**：选 **业务表单**（不是"流程表单"）；
   - **表单提交路由**：`/clm/contract/create`
   - **表单查看地址**：`/clm/contract/bpm/index.vue`
   - 这两项让 BPM 把"发起"跳到合同创建页、把审批详情页内嵌合同快照（含绑定正文版本下载）。
4. **③ 流程设计**：在画布上点节点间的 **+** 号添加：
   - **审批人节点**：审批人策略支持 指定成员 / 部门负责人 / 连续多级部门负责人 / 岗位 / 用户组 / 发起人自选 / 发起人自己 / 表达式等；多人时可选 或签/会签/依次审批；可配拒绝后处理（结束流程/退回）；
   - **抄送节点**、**条件分支**（例如 `${amount > 100000}` 走总经理加签——金额、部门、类型编码已作为流程变量传入，变量名：`amount`、`ownerDeptId`、`contractTypeCode`）。
5. **④ 更多设置**（超时提醒、自动通过等，可全部默认）→ 右上【保存】→ 回到模型列表点【发布】。
6. **让某个合同类型走这条流程**：合同管理 → 合同类型 → 版本/设计 → 草稿版本【设计表单】→ 顶部「审批流程」选成新流程 → 保存并发布。（不同合同类型可以走不同流程。）

> 改已发布的流程：模型上点【修改】调整后再点【发布】即生成新版本；审批中的老实例继续走老版本，新提交走新版本。

## 四、新建审批流的表单

分两种场景：

| 场景 | 做法 |
|---|---|
| **合同审批**（本系统主路径） | 不需要在 BPM 里单独建表单。审批内容 = 合同本身（核心字段 + 合同类型的扩展字段快照 + 绑定的正文版本）。所以"审批流的表单"就是**第二节的合同类型表单设计**；流程模型里表单类型固定选「业务表单」。 |
| **非合同的独立审批**（例如以后单独做用章申请、付款申请这类通用单据） | ①「流程表单」入口当前默认隐藏（合同审批用不到），需要时在 **系统管理 → 菜单管理** 搜索「流程表单」把可见状态改为显示；② **流程配置 → 流程表单** → 【新建】，用同一套拖拽设计器画表单并保存；③ 新建流程模型时第②步表单类型选「**流程表单**」并选中它。发起时 BPM 自动渲染该表单，数据存在流程实例里（不落业务表）。同理，隐藏的「发起流程」入口也在菜单管理里恢复。 |

## 五、新建合同 → 提审 → 审批（完整闭环）

**经办人：**
1. **合同管理 → 合同台账** → 【新建】（首页工作台右上角的【新建合同】是同一入口；原 BPM「发起流程」页已隐藏，合同统一从台账新建）。
2. 填写：标题、**合同类型**（选中后下方自动出现该类型的扩展字段）、金额/币种、签订/生效/到期日期、**我方主体**、**相对方**、说明 → 【保存草稿】→ 自动进入合同详情。此时生成合同编号 `HTyyyyMMdd-xxxxx`。
3. 详情页 **「正文与附件」** Tab → 【上传正文新版本】上传 DOCX/PDF。每次上传都是**新版本**（v1、v2…，带 SHA-256 校验和），旧版本永不覆盖。附件走【上传附件】。
4. 点右上【**提交审批**】：弹窗显示将绑定的正文版本与校验和、审批人预览（流程有"发起人自选"节点时在此选人）→ 确认。合同进入「审批中」，**正文与表单即被锁定/冻结**。
5. 审批中可在「审批记录」Tab【查看流程】追进度；提交人可【撤销审批】。被驳回后：上传新正文版本 → 再次提交（生成新的审批记录，旧记录完整保留）。

**审批人：**
6. **审批中心 → 待办任务**（首页工作台的「我的待办」也可直达）→ 点【审批】进入流程详情：页面内嵌合同快照（核心字段、签约方、扩展字段、绑定正文版本可下载）→ 填意见【通过】或【拒绝】。全部节点通过后合同自动变为「审批通过 / 已批准」。

**授权与审计：**
- 合同默认只有负责人和参与人可见（**管理员也看不到未授权合同**）。详情「参与人」Tab →【编辑参与人】可把同事加为协作人/查看人并勾选 查看/编辑/下载 权限，保存即时生效；
- 「审计轨迹」Tab 记录创建/修改/上传/下载/提审/审批结果/授权变更全过程。
