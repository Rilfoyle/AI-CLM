## Module Impact

- Active / affected module：演示与测试支撑、角色化工作视图、一期合同前段流程的信息架构。
- `plan.md` update：最终交付支持“空客户基线”和“可演示基线”两个显式入口；当前本地环境采用演示基线。
- `prd.md` update：不修改核心对象、角色、审批完成终点或系统管理员无合同正文权限。
- Artifact root：`docs/yinuo-replica/`。

## Apply Now

- 为四个固定单角色账号提供 local-only 快速切换，签发真实用户 token 并重新加载菜单与权限。
- 建立 4 份原创合同范本、4 类合同类型、虚构参与方、一期合同样例和标准审批流程。
- 演示记录只覆盖草稿、协同、待审批、退回与审批完成，不生成签署、归档或履约数据。
- 左侧菜单和首页任务编排靠近一诺可见行为，并保持每个角色的真实权限差异。
- 数据脚本采用固定编码和可核验计数；清理边界只触及带 TuriX 演示标识的数据。

## Hold / Needs Decision

- 不复制一诺租户中的真实公司、联系人、手机号、合同正文、附件或客户业务数据。
- 不复制一诺源码、品牌素材或像素级视觉资产，只复刻通用业务结构和交互节奏。
- 不启用框架通用 mock-user 能力，不把共享密码下发到前端，也不让生产环境开放身份切换。
- 用章、电子签、纸质签约、归档、履约、变更、续签和关闭仍在一期范围之外。
