# 合同在线编辑技术选型调研（2026-08-24）

> 需求：P1 = 在线编辑 + 批注 + 历史版本 + **内容级对比（红线）**；P2 = 多人协同编辑。
> 阶段约束：POC 可接受云 API 服务；**上线交付必须支持独立/私有化部署**（客户可能是纯内网）。
> 所有定价/许可均于 2026-08-24 从官网一手来源核实（并经独立核查代理二次回查）；查不到公开价的一律标"需询价"。完整来源清单见文末。
> 校准基准：我们的 CLM 底座已实现"令牌文件服务 + 保存回调→不可变版本+SHA-256 + 稳定 document key + JWT 签名"，任何"JS SDK + 回调"型组件都能复用这套管线，下述工程量均为**增量**人日。

## 1. 评审口径

- P1 逐项：浏览器内 DOCX 编辑｜批注（comments）｜修订留痕（track changes）｜历史版本（我们自己的不可变版本链，编辑器只需挂接）｜**内容级对比**（产出可逐条接受/拒绝的红线，不是并排展示）。
- P2：多人实时协同。
- 交付约束：客户现场独立部署（可能离线内网）、中文合同版式保真（页眉页脚/表格/盖章图片/公文字体）、许可允许"部署到第三方客户"（这是很多组件从"内部使用"跳到"OEM/转售"档位的分水岭）、30 万项目的成本占比。

## 3. 各组件详评

### 3.1 ONLYOFFICE Docs（主线推荐）

- **版本与关键变化**：v9.4（2026-05）起 **Community 版取消 20 并发限制**、免 RabbitMQ/数据库、单进程运行（官方博客原文确认）。三版本：Community（AGPLv3）/ Developer（集成商白标转售）/ Enterprise（企业自用）。
- **P1 逐项**：编辑/批注/修订全版本；**内容级对比全版本内置**（集成方实现 `onRequestSelectDocument` → `setRequestedDocument(type:"compare")`，差异以修订呈现、逐条接受/拒绝；旧 API `setRevisedFile` 曾是付费版专属、7.5 起废弃——**POC 必须在 Community 9.4 上实测 Compare 按钮**）；历史版本由集成方实现（`onRequestHistory/refreshHistory/setHistoryData/onRequestRestore`），恰好对接我们的不可变版本+SHA-256。P2 协同全版本内置，零额外开发。移动端网页编辑 Community 无（验收若含手机编辑则必须付费版）。
- **许可**：AGPL 网络条款下部署给客户、用户经浏览器访问属"网络提供"；不修改 Document Server 本身时，通行理解是提供其原始源码链接+保留品牌即可，且我们经 HTTP API 集成的 CLM 后端是独立程序、一般不构成衍生作品——**官方 FAQ 未直接裁定这一点，商用交付前应做合同评审**（核查代理已确认 FAQ 原文与这条解释边界）。官方明确 Community 定位"测试/个人/小规模"，生产"推荐"商业版。
- **定价**：DE **$3,500 起**/服务器（20 并发，含 1 年更新支持，白标）；EE "From $1,500"，配置器示例 50 并发/1 年/Basic 支持 = **$2,100**；更高并发需询价。国内可走金牌经销商（慧都 evget 等）人民币结算+增值税发票。
- **部署**：Docker（2C/4GB/40GB 起）或 **Windows 原生安装包**（契合当前交付环境）；ARM64 官方镜像（鲲鹏/飞腾可跑）；LoongArch 无支持；可完全离线。中文字体需装入服务器并跑 `documentserver-generate-allfonts`（宋体等为授权字体，用客户环境字体或换思源/Noto CJK）。
- **工程量（我们仓库）**：部署+JWT 联调 0.5–1d；真实合同端到端 1–1.5d；历史版本 UI 挂接 1–2d；Compare 挂接 1–1.5d；字体+版式验证 0.5–1d ⇒ **合计 4–7 人日**。
- **优劣势**：➕ 零迁移（管线已建成）、P1/P2 全覆盖、唯一"编辑器内置内容级对比"且免费版可用、合规路径清楚、价格透明便宜。➖ 中文公文类版式保真弱于 WPS（需真样本验证）、无信创认证记录、Community 无 SLA。

### 3.2 WPS WebOffice（云端 + 私有化）

- **云端版能力**：编辑/批注/修订（JSAPI `Revisions` 完整：逐条/批量接受拒绝、`Json()` 导出全部修订）/历史版本（接入方实现 versions 三接口）/协同（≤200 人）都齐；**唯独没有文档对比**——全站无对比 API/功能，桌面 WPS 才有"审阅→比较"。这是 P1 的直接缺口。
- **云端版约束**："平台仅支持公网的能力"（官方 FAQ 原文）：回调接口必须公网可达、文档内容经金山云集群处理 ⇒ **合同出内网**，保密型客户不可接受；正式应用需企业开发者认证（营业执照）。测试应用免费 3 个月（≤30 次调用、并发≤2、带水印）。
- **云端定价**（官方价格页，核查已逐项确认）：按量 = 单日最大并发文档数阶梯 **2.5 / 2.2 / 2.0 元·并发·日**（1–20/21–50/51–100 档，>100 询价）+ **每月保底 750 元**；单文档默认 ≤100M，每 +100M 加 300 元/月；包年套餐 20/30/50 并发 = **18,000 / 25,920 / 41,760 元/年**（此表为官网图片价，核查代理未能 OCR 原图，但与按量价算术自洽；下单前人工复核）。
- **私有化版**：官方无产品页、无公开价格、无公开部署规格，**一切需询价**（400-677-5005 转 2）。网传"几十万级"无可靠出处，本报告不采信。未见允许 ISV 再分发/OEM 的公开条款——交付大概率是金山与客户（或我方）直签商业合同，商务周期需提前启动。
- **集成模型**：前端 `web-office-sdk-solution` iframe + 我方实现 7 组回调（文件元数据/下载/权限位/用户信息/三阶段保存 prepare→address→complete/版本三接口/可选水印与事件通知），签名 `WPS-2:AppId:SHA1(...)`；三阶段保存声明 digest 支持 sha256——与我们现有"回调→不可变版本+SHA-256"几乎同构。文件 ID ≤47 字符、版本号 int32 递增，均兼容。**工程量 ≈ 5–7 人日**（+POC 内网穿透 0.5–1d）。
- **优劣势**：➕ 中文合同/公文场景保真全场最强（公文字体、页眉页脚、水印、公文域 JSAPI）、信创头部厂商、协同成熟。➖ **无内容级对比 API（必须外挂对比引擎）**、云端版合同出内网+回调公网、私有化价格与规格黑盒、无公开 OEM 条款。

### 3.3 Collabora Online（最强开源备选）

- CODE 免费但官方明示"不建议生产"（社区流传 10 文档/20 连接软限制，**官方页面无此数字**，核查标记为非官方）；Business 订阅 **€3/用户/月**（≤99 人，官方页确认；50 人≈¥1.5 万/年）；Enterprise 100+ 询价。MPLv2——交付客户合规清晰，无强制服务器费。
- P1：编辑/批注/修订齐；**内容级对比 25.04 版新落地**（REST `compare=` + Review 页签交互式 Compare），但核查确认演示发生在**开发版**，正式 LTS 版的可用性与中文对比质量必须先实测。P2 协同是产品核心，零额外开发。
- 集成 = WOPI host（CheckFileInfo/GetFile/PutFile 三端点 + discovery），与现有管线同构，**5–8 人日**。部署 Docker（约每用户 50MB 内存），ARM64 官方支持，可离线；中文字体必须挂载到 Collabora 专用目录，LibreOffice 引擎对 Word 复杂版式保真中等——真实合同样本验收是硬前置。
- 定位：若最终不想付 ONLYOFFICE DE 又要纯开源合规，Collabora 是替补；但"对比太新 + 中文保真中等"两个风险叠加，当前不作主线。

### 3.4 Office Online Server —— 排除

微软官方生命周期页确认 **2026-12-31 退役**、无本地后继产品；Web 端无修订/无对比（P1 两项硬伤）；编辑要求客户自持每用户 Office 批量许可+SA，ISV 不能代分发。**不可行，不再投入。**

### 3.5 永中 Web Office / 其他国产

- **永中**：私有化与**信创履历全场最强**（飞腾/龙芙/鲲鹏/麒麟/统信）；但 Web 端修订/对比/JSSDK 成熟度无公开文档可查，全线需询价。定位 = 客户信创硬指标下的备胎，先要测试包实测再谈。
- **不适合项**（结论一行版）：Univer（Doc 未 production-ready，DOCX 编辑属商业版且非保真编辑）；石墨/腾讯文档/飞书私有化（协同文档模型≠DOCX 保真编辑，套件式采购与 30 万预算错配）；数科网维/福昕（OFD/PDF 版式线，仅适合定稿后"版式固化+签章+归档"下游环节）；NTKO/金格类网页内嵌本地 Office 控件（依赖客户端装 Office+浏览器中间件，Chrome 兼容性持续恶化，无真协同）。
